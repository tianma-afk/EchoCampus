# 算法后台启动文档

## 开发环境

### 1. 安装 uv

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 2. 安装依赖

在 `backend_py` 目录下，根据硬件选择 PyTorch 后端：

```bash
uv sync --extra cu126    # NVIDIA GPU（Maxwell 架构及以上）
uv sync --extra directml # DirectX 12 兼容显卡（Windows）
uv sync --extra cpu      # 无显卡 / 仅 CPU
uv sync --extra xpu      # Intel GPU
```

如果 `requirements.txt` 有新增依赖：

```bash
uv add -r requirements.txt
```

### 3. 下载模型权重（首次必须执行）

```bash
uv run python scripts/download_models.py

# 国内网络使用 HuggingFace 镜像：
HF_ENDPOINT=https://hf-mirror.com uv run python scripts/download_models.py
```

脚本会下载：DINOv2 仓库、DINOv2 预训练权重、Pair-VPR 模型权重。已下载的文件自动跳过（幂等）。

### 4. 配置环境变量

```bash
cp .env.example .env
```

按需修改 `.env` 中的配置（Milvus 地址、MinIO 密钥等）。

### 5. 启动开发服务器，在backend_py 目录下启动虚拟环境
.venv\Scripts\Activate.ps1
```bash
cd app
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

接口文档：http://127.0.0.1:8000/docs

### 6. 测试

```bash
# 在 backend_py 目录下执行

# 一、全流水线测试（提取 → 插入 → 搜索 → 重排序）
uv run --extra cu126 .\app\test.py

# 二、FastAPI /search 接口测试（GUI 选图）
# 先启动 main.py，再运行：
python .\app\FastAPI_test.py
```

## 生产环境

### Docker 构建与部署

镜像构建时自动执行 `scripts/download_models.py` 预下载所有模型权重，运行时**不再联网**。

```bash
# 在项目根目录
docker compose build backend-py
docker compose up -d
```

服务端口：`8000`

### 模型权重缺失的处理

如果容器启动时报 `FileNotFoundError: 模型权重文件缺失`，说明镜像构建时下载失败。解决方法：

1. 检查构建日志中的下载错误
2. 设置镜像环境变量重试：
   ```bash
   HF_ENDPOINT=https://hf-mirror.com docker compose build --no-cache backend-py
   ```
3. 或在开发机手动下载后打包进镜像（不推荐）

### 环境变量

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `HF_ENDPOINT` | HuggingFace 镜像地址（构建时使用） | `https://hf-mirror.com` |
| `MILVUS_URI` | Milvus 向量数据库地址 | `http://localhost:19530` |
| `MINIO_ENDPOINT` | MinIO 对象存储地址 | — |
| `MINIO_ACCESS_KEY` | MinIO 访问密钥 | — |
| `MINIO_SECRET_KEY` | MinIO 秘密密钥 | — |
| `MINIO_BUCKET` | MinIO 存储桶名称 | — |
