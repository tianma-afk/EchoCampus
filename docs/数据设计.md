地标landmark

```Plain
id    uuid    主键
name    str    地标名称
check_in_count    int    打卡人数
landmark_category_id    uuid       地标分类外键
built_time    str    建造时间
open_time    str    开放时间
description    str    地标简介
landmark_location_id    uuid    地标位置外键
recommendation_score_sum    int    推荐指数总分数
recommendation_score_count    int    推荐总人数
tags    json    标签
description    str    地标位置大致描述
campus_id    uuid    校区外键
```

楼层floor

```Plain
id    uuid    主键
landmark_id    uuid    地标外键
floor_number    int    楼层数（1是正一层，-1是负一层，0是室外）
floor_name    str    楼层名
tags      json      楼层标签（如'["教室","自习区"]'）
```
