## 获取地标列表

支持功能：分页获取，可以选择地标分类（不填则为全部），可以选择模糊查询地标名称（不填则为全部），可以选择是否按推荐程度从高到低返回（默认则不按推荐程度）

### 请求格式

```Plain
GET /api/v1/landmarks/page
```

**请求参数（****Query** **String）：**

| 参数        | 类型 | 必填 | 说明                                   |
| ----------- | ---- | ---- | -------------------------------------- |
| pageNum     | int  | 否   | 页码，默认 1                           |
| pageSize    | int  | 否   | 每页条数，默认 10，最大 50             |
| category    | str  | 否   | 地标分类，不填则查全部                 |
| keyword     | str  | 否   | 地标名称模糊查询关键词                 |
| sortByScore | bool | 否   | 是否按推荐指数从高到低排序，默认 false |

**请求示例：**

```Plain
GET /api/v1/landmarks/page?pageNum=1&pageSize=20&category=文化建筑&keyword=图书&sortByScore=true
```

## 补充说明

### 按推荐指数排序逻辑

当 `sortByScore=true` 时：

- 按 `score` 降序排列
- 相同分数的按 `check_in_count` 降序（打卡人数多的排前面）
  - 

### 模糊查询逻辑

当 `keyword` 有值时：

- 对 `landmark.name` 进行模糊匹配：`LIKE '%keyword%'`
- 不区分大小写（PostgreSQL 可用 `ILIKE`）
  - 

### 分页默认值

| 参数        | 默认值 |
| ----------- | ------ |
| pageNum     | 1      |
| pageSize    | 10     |
| sortByScore | false  |
